# Q3.1 activation boundary

The checked-in pilot budget is an inert template. It cannot execute training.

One interactive authorization may materialize exactly one runtime budget that
binds:

- the exact local source commit;
- diagnostic seed 2;
- 7,685 trainable head parameters;
- at most 100 optimizer updates;
- the 9,000/500 private split;
- at most $0.10 of pilot compute;
- no public quantity, language, promotion, or deployment authority.

The runner writes a consumption marker before invoking the mechanics binary.
It refuses an existing output directory or consumed authorization. There is no
Make target that trains the head.

Passing the private selector freezes one candidate checkpoint only. Every
downstream gate requires separate authorization. Seeds 1 and 3 remain sealed.
