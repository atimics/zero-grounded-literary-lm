# Reasoner 5.4 preregistration

The contract and source hashes fix the task, controls, and decision rule.
The source prior is frozen before the target episodes. The run has one
exclusive execution lock and a 300-second watchdog. Publication includes
the recorded decision, each episode, learned artifact, and file hashes.

The primary condition is the synthetic pixel channel with one changed pixel per glyph.
All other conditions are retention checks. The contract provides the full
scope and measurement definitions.
