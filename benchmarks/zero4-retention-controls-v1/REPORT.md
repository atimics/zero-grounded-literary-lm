# Retention control runner: engineering result

All five arms completed the native smoke. The four active arms each made four
training attempts, with evaluation at initialization and after every attempt.
The comparison produced 79 native process records. The three replay arms used
the same four training windows.

All arms produced zero correct final artifacts on the five known quantity
cases. Each also scored five on argument binding and oracle arithmetic. The
evaluator computes those two fields from the supplied input and bound target
request. The final artifact count measures the complete model-driven path.
Keep these counts separate when interpreting a future result.

The guarded arms each used backtracking on the first attempt. Projection stayed
inactive in the four-attempt fixture. The native numerical test separately
passed 35 checks, including an active tangent projection and restoration of
weights and optimizer moments. This smoke supplies engineering evidence for
the runner. A fresh-data comparison will measure the research effect.

## Failures retained

The first fixture used learned positions. Retention evaluation succeeded, then
export rejected it because the quantity evaluator requires a rotary model.
All five failed arms retained their output and terminal records. The fixture
now uses the rotary preset, and the manifest checks that format before scoring.

The first version of that preflight read the alignment padding as the model's
flags. It rejected the valid rotary fixture. The corrected parser reads the
nine integer header fields and checks the flags field at its actual offset.

The smoke retains its zero final-artifact count and inactive projection. These
observations belong to the known toy fixture. The earlier Q2.6 scientific
results keep their original scope and authority.
