## Interpretation

This is evidence for a reusable relational edit rule inside this exact task
family. Training on 1D/2D produced a policy that passed the complete 3D
development world. Training through 3D left the same weights, and those
weights then passed the complete 4D world. The fixed 3D hash policy did not
transfer.

The result does not establish general mathematical reasoning. The state domain,
atom language, verifier, and axis-aligned box structure are still fixed. A
fifth independent coordinate would mostly repeat the same factorized rule and
is not a strong next test.

The next useful gate should change structure: transfer from independent unary
bounds to coupled integer difference constraints such as `x_i - x_j <= c`.
That keeps exact local verification while testing variable-size relational
graphs, witness-directed tool use, and composition across coordinates.
