# Reasoner (3,9): active law invention

Reasoner (3,9) replaces the fixed polynomial feature map with a small typed
integer program language. It enumerates and canonicalizes programs, keeps the
version space consistent with raw comparison examples, asks a minimax query
when the law is ambiguous, and commits only when one semantic class remains.

The curriculum contains individual fold programs. Development contains unseen
two-fold compositions. The fresh cloud-only seal contains unseen three-fold
compositions in larger dimensions.

The public development screen will run with:

```sh
make reasoner310-check
./reasoner310 development
```

The sealed command is locked until its source bundle and cloud contract are
frozen and explicitly authorized.
